# Задача: написать 2 комедийных сценария на утренние темы

15.09.2026 → 16.09.2026: по просьбе Ника утренний формат (3 темы/день)
теперь смешанный — **2 из 3 темы делаются в комедийном формате
Рублёнка** (тот же мультяшный стиль, что уже вечером — см.
`scripts/social/generate-comedy-short.mjs`), а **третья тема — как
раньше**, обычным форматом (реальный скриншот страницы + начитка сути).
Какая тема какая — решает не агент, а сам рендер-скрипт (он смотрит,
есть ли для темы готовый сценарий в файле, который ты пишешь); твоя
задача — просто написать сценарии для первых двух тем.

## Отличие от вечернего формата

Вечерний формат — только раздел `moshennichestvo`, там всегда есть
«злодей» (мошенник). Утренние темы — **любой раздел сайта**
(приставы, банкротство, займы, ипотека, семья и деньги и т. д.), и там
не всегда есть злодей-человек — иногда это просто сложная жизненная
ситуация. Поэтому рамка сценария шире:

- Если в теме реально есть недобросовестная сторона (мошенник,
  коллектор, который угрожает, работодатель, который не платит) —
  можно делать классическую «злодей проигрывает».
- Если темы — просто трудная ситуация без злодея (например, ипотечные
  каникулы, банкротство, алименты) — веди сценарий как «проблема
  наступает → герой находит правильный ход → проблема отступает», без
  искусственного злодея. Эмодзи-образ проблемы вместо персонажа
  (📉/💸/⚖️/😰 и т. п.).

## Шаг 1 — определи 2 темы

Прочитай `scripts/social/posted-social.json` (массив уже
опубликованных slug'ов утреннего формата — общий трекер, не зависит от
того, каким стилем видео сделано). Пройди по `TOPICS`
(`content/index.mjs`) в их естественном порядке и найди **первые две**
темы, чей `slug` НЕ входит в `posted-social.json`. Именно эти две —
твои темы (третья по порядку столько же не опубликованная тема
достанется обычному формату — ты её не трогаешь).

Прочитай реальный контент каждой темы (`sut`, `first`, `steps`, `law`,
`dont`) — сценарий должен опираться на настоящие факты темы, не
выдумывать новых.

## Шаг 2 — напиши сценарии

Структура каждого — 6 сцен, объект `{ bg, emoji, headline, bubble,
narration, domain? }`:

1. **Интро с маскотом** — `emoji: '💰'`, `headline: 'Рублёнок
   рассказывает'`, `bubble` — короткий тизер темы, `domain:
   'kodeksdeneg.ru'`, `narration`: «Рублёнок — герой проекта «Кодекс
   денег» — сегодня показывает [суть темы].»
2. **Проблема заявляет о себе** — злодей ИЛИ эмодзи-образ ситуации (см.
   выше, зависит от темы).
3. **Ситуация развивается** — сама проблема в действии, по реальному
   механизму темы.
4. **Твист — герой не поддаётся / находит выход** — конкретная деталь
   из реального `first`/`steps`/`law` темы, не выдумка.
5. **Проблема отступает** — комедийная развязка, коротко и хлёстко.
6. **Payoff + сайт** — реальный совет (из `first`/`steps`) +
   `domain: 'kodeksdeneg.ru'` в бабле + narration: «Рублёнок и
   подробный разбор — на сайте кодекс денег точка ру.»

`bg` — CSS `linear-gradient`, тревожный для проблемы / светлый для
победы (примеры бери из `PILOT` в `generate-comedy-short.mjs`).

## Что НЕ делать

Те же правила, что и у вечернего формата: без национальных/этнических/
гендерных стереотипов у «злодея»; не выдумывать юридические факты; не
копировать текст темы дословно (пересказ живым языком); `narration` —
без цифр цифрами (числа словами); весь ролик 45-60 секунд озвучки
(~110-140 слов на сценарий).

Описание к посту (caption) — как и вечером, собирается автоматически
внутри `renderComedyVideo()` по `slug`, ничего не пиши в
`caption`/`description` сам.

## Куда сохранить

Запиши **массив из двух объектов** (именно массив — не один объект,
как в вечернем формате, здесь их два) в файл
`scripts/social/morning-comedy-scripts.json`:
```json
[
  { "slug": "<slug-темы-1>", "title": "<заголовок, до 90 символов>", "scenes": [ ... 6 объектов ... ] },
  { "slug": "<slug-темы-2>", "title": "<заголовок, до 90 символов>", "scenes": [ ... 6 объектов ... ] }
]
```

Если подходящих неопубликованных тем меньше двух — запиши сколько есть
(даже пустой массив `[]`, если тем нет вообще). Не запускай рендер и не
публикуй сам — это сделает `daily-social-post.mjs`. Не трогай
`posted-social.json` — его обновляет сам скрипт после публикации.
